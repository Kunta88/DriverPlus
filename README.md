# DriverPlus — модификация «21 ВЕК Водитель»

Текущая версия: **0.15.277.coreonly**, versionCode **277**, пакет
`com.tx.driver.vek.znamenskoe`, target SDK **34**.

Готовая подписанная APK: [выпуск v0.15.277](https://github.com/Kunta88/DriverPlus/releases/tag/v0.15.277).

[Скачать APK напрямую](https://github.com/Kunta88/DriverPlus/raw/refs/heads/main/downloads/DriverPlus-0.15.277.coreonly.apk).

Это модификация декомпилированного приложения, не исходный проект разработчика
и не сервер таксопарка. APK предназначена для проверки пользователем в своём
таксопарке. Изменение клиента не отменяет требования и ограничения сервера.

## Что изменено

- Чёрная тема, белый текст, крупная целая сумма таксометра; портретная и альбомная
  компоновка. Смысловые цвета, карты и системные элементы не обязаны быть монохромными.
- Переключатели автопринятия и автоприбытия/посадки. После подтверждённого прибытия —
  пять минут ожидания; ранняя посадка при отъезде примерно на 200 м требует
  предварительных 15 секунд в зоне подачи и подтверждения точными GPS-измерениями.
  Рабочие переходы используют существующие команды и подтверждения сервера.
- Звук автопринятия из пользовательского MP3 на шесть секунд с вибрацией на шесть
  секунд, защита от повторов; ICQ для сообщений диспетчера. Максимизация системного
  потока громкости не обходит ограничения Android и режим «Не беспокоить».
- Автовход с сохранёнными данными без автоматического открытия смены; защищённое
  хранение пароля/черновиков на Android 23+ и восстановление сетевой конфигурации.
- Переработанные TCP-клиент и декодер, ограниченные HTTP-запросы, восстановление
  после смены сети, сохранение черновика при проблемах отправки.
- Индикатор отдельно показывает основной канал и состояние веб-запросов. Старое
  сообщение о веб-ошибке больше не обозначает доказанный текущий отказ сервиса.
- Отправка свежей позиции при неподвижной машине, после переподключения и смены
  заказа; без воспроизведения очереди устаревших координат.
- Пять независимых энергетических настроек без изменения формулы тарифа.
- Сохранение ручного выбора перерыва. При расхождении с сервером — пояснение;
  клиент не может запретить серверу менять действительную доступность водителя.
- Только страница «Эфир» без строки вкладок; Google как фиксированный поставщик
  карт; скрыты отдельные переключатели стоянок с закреплением значений.
- Самозакрытие GPS-диалога при включении GPS; полное локальное закрытие приложения
  с остановкой службы и соединения до следующего явного запуска.
- Новости и фотоконтроль отключены локально вместе с фоновыми запросами,
  уведомлениями, экранами, диагностикой и влиянием их ошибок на индикатор.
- Адаптация разрешений, foreground-службы, хранилища и системных API для Android 16.
  Это target-34 сборка, а не полная миграция на target 36.

Подробности последнего выпуска: [docs/RELEASE-277.md](docs/RELEASE-277.md).

## Исходники, сборка и проверки

- `vek_decoded/`: ресурсы и smali, включая актуальные сгенерированные помощники.
- `mods/`: Java-помощники, тестовые заглушки, сценарии сборки и проверки.
- Основная инструкция стабильности: [mods/STABILITY.md](mods/STABILITY.md).
- Полная сборка: `bash mods/build-apk.sh` с установленными Apktool, JDK,
  Android SDK Build Tools 35.0.1 и Android API jar, указанными в скриптах.
  Пути по умолчанию рассчитаны на исходную macOS-среду; их нужно адаптировать.
- Для пересборки уже подготовленного smali можно использовать обычный Apktool,
  затем zipalign и apksigner. Временные SDK jar не входят в репозиторий.
- Локальный ключ подписи не публикуется. Для обновления поверх установленной
  версии требуется тот же ключ; чужой ключ не сохранит совместимость обновления.

Промежуточные `build/`, неподписанные APK и журналы устройства не публикуются.
Тестовые заглушки не включаются в приложение. JVM-тесты не заменяют реальные
испытания с телефоном и сервером. Распределение заказов остаётся за таксопарком.
